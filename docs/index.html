A collection of utility scripts for molecular dynamics post-processing — format conversion between XYZ, LAMMPS data files, and NEB configurations; structural analysis of KMC trajectories; and event application from ARTn output.

Most scripts depend only on the Python 3 standard library and can be run directly from any working directory. Scripts requiring external packages note their dependencies explicitly below.

Python 3 LAMMPS ARTn KMC / pykmc NEB OVITO
Dépendances
Python ≥ 3.6 Tous les scripts
pandas show_basin_connectivity.py
OVITO view_trajectory.py
PySide6 view_trajectory.py

Cinq des sept scripts n'ont aucune dépendance externe — la bibliothèque standard Python 3 suffit (argparse, math, re, sys, os).

apply_event.py Python

Applies an ARTn event to a LAMMPS data file to produce saddle-point and final-state configurations.

Reads three inputs — a LAMMPS initial configuration, an ARTn event file identifying the cluster atoms, and a three-frame XYZ file (initial, saddle, final) — computes atomic displacements, and writes two new LAMMPS data files with periodic boundary conditions applied by default.

Usage 
./apply_event.py init.data event_file event.xyz [options]

# with a custom output base name
./apply_event.py conf.data event_001 event_001.xyz -o run_001

# disable PBC, show top 20 displacements
./apply_event.py conf.data event_001 event_001.xyz --no-pbc --top 20
Argument Description
init.data required LAMMPS initial configuration (.data)
event_file required ARTn event file — cluster atom IDs
event.xyz required XYZ file with 3 frames: initial, saddle, final
-o, --output optional Output base name (default: derived from input)
--saddle-out optional Explicit path for saddle-point output
--final-out optional Explicit path for final-state output
--no-pbc optional Disable periodic boundary condition wrapping
-v, --verbose optional Print per-atom displacements
--top N optional Print the N largest displacements (default: 10)

Outputs: <base>_saddle.data <base>_final.data

neb_conf2lammps.py Python

Converts NEB endpoint configurations to LAMMPS data format.

Merges box geometry and atom IDs from the initial NEB configuration with the atomic positions from the final NEB configuration, producing a LAMMPS-ready .data file. Verifies that both files describe the same number of atoms.

Usage 
./neb_conf2lammps.py neb_ini.conf neb_fin.conf
./neb_conf2lammps.py neb_ini.conf neb_fin.conf -o final_state.data
ArgumentDescription
ini_file required Initial NEB configuration (LAMMPS format)
fin_file required Final NEB configuration with target positions
-o, --output optional Output path (default: fin_file with .data extension)
show_basin_connectivity.py Python

Displays and filters a basin connectivity DataFrame from a pykmc pickle file.

Reads a pandas pickle containing the basin_connectivity DataFrame produced by pykmc simulations. Supports state-to-state filtering and optional CSV export. Handles cross-version pandas compatibility automatically.

Usage 
# default file (basin_connectivity_1.pickle)
python3 show_basin_connectivity.py

# specific file + filter by state + export
python3 show_basin_connectivity.py run_42.pickle \
  --state 5 --to-state 3 --csv transitions_5to3.csv
ArgumentDescription
pickle_file optional Pickle path (default: basin_connectivity_1.pickle)
--state N optional Filter rows where column state == N
--to-state N optional Filter rows where column state_connexion == N
--csv FILE optional Export filtered table to CSV

Requires: pandas

view_trajectory.py Python

Interactive 3-D viewer for KMC trajectories using OVITO.

Loads a multi-frame XYZ trajectory and renders it in an OVITO viewport with a Qt interface. Features include frame-by-frame navigation or auto-play, Common Neighbor Analysis (CNA) to identify structural defects, and optional FCC-atom masking to isolate non-FCC environments.

Usage 
# default trajectory file (trajkmc.xyz in cwd)
python view_trajectory.py

# explicit trajectory path
python view_trajectory.py simulations/run_07/trajkmc.xyz

# show built-in documentation
python view_trajectory.py --info
ArgumentDescription
fichier.xyz optional Trajectory file path (default: trajkmc.xyz)
--info optional Print documentation and exit

Requires: OVITO PySide6

xyz2lammps.py Python

Converts extended XYZ files to LAMMPS atom_style atomic data files.

Parses extended XYZ headers to extract simulation box geometry (including triclinic parameters), maps element symbols to LAMMPS atom types with standard atomic masses, and supports multi-frame trajectory files via the --frame flag. No external dependencies required.

Usage 
# basic conversion (output: input.data)
./xyz2lammps.py structure.xyz

# specify output and element symbols
./xyz2lammps.py structure.xyz -o al2o3.data --symbols Al,O

# pick frame 5 from a trajectory
./xyz2lammps.py traj.xyz --frame 5

# list all available frames
./xyz2lammps.py traj.xyz --list-frames
ArgumentDescription
input required Extended XYZ file (single structure or trajectory)
-o, --output optional Output path (default: input with .data extension)
--frame N optional Frame index to convert (default: 0)
--list-frames optional List all frames in file and exit
--symbols optional Comma-separated element symbols for type mapping, e.g. Si or Al,O
xyz_distance.py Python

Computes the structural distance (RMSD) between two atomic configurations.

Accepts XYZ and LAMMPS data files interchangeably (format detected from extension; overridable). Atoms are matched by id field when available, otherwise by line order. Reports RMSD in Å, per-component RMS (dx, dy, dz), maximum displacement, and energy difference when present in both files.

Usage 
# compare two LAMMPS data files
./xyz_distance.py initial.data final.data

# compare specific frames from an XYZ trajectory
./xyz_distance.py traj.xyz ref.xyz --frame-a 10 --frame-b 0

# verbose: show per-atom displacements, top 5
./xyz_distance.py A.data B.data -v --top 5

# disable PBC (isolated cluster)
./xyz_distance.py A.xyz B.xyz --no-pbc
ArgumentDescription
fichier_A required First configuration — XYZ or LAMMPS data
fichier_B required Second configuration — same or different format
--frame-a N / --frame-b N optional Frame index to read from each XYZ file
--format-a / --format-b optional Force format: xyz or lammps (overrides extension detection)
--no-pbc optional Disable periodic boundary conditions
-v, --verbose optional Print per-atom displacement vectors
--top N optional Print the N most-displaced atoms

Output: RMSD (Å) · max displacement · RMS per component · ΔE (if available)

nettoyage.sh Shell

Removes LAMMPS and pykmc simulation output files from the working directory.

Usage 
# run from your simulation directory
bash nettoyage.sh

# or mark executable once
chmod +x nettoyage.sh
./nettoyage.sh
